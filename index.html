About ShopSphere QA Sandbox

ShopSphere is an open-source demo storefront purpose-built as a QA portfolio project. It simulates a realistic e-commerce experience — product discovery, cart management, promo codes, and a multi-step checkout — so testers can practice manual test case design, exploratory testing, Jira bug logging, and end-to-end automation with tools like Playwright and Cypress.

Every interactive element exposes a data-testid attribute, key user actions emit simulated GA4 analytics events on window, and a mock REST layer returns realistic 200/400/404 responses for API-level validation.

This build also contains a handful of intentionally planted bugs for bug-logging practice — see the README for details.
